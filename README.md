# Расписание

Приложение для iPhone: загружаете своё расписание пар, и виджет на заблокированном экране показывает, какая пара следующая, во сколько она начинается и в какой аудитории.

- **Виджеты на экране блокировки.** Прямоугольный под часами: время, предмет, аудитория. Во время пары он показывает, когда она закончится и что будет дальше. Однострочный над часами: «10:40 Матан · 305». Круглый: время начала и аудитория.
- **Виджет на домашнем экране** с обратным отсчётом до пары.
- **Числитель и знаменатель.** У каждой пары можно указать, по каким неделям она идёт: каждую, по нечётным или по чётным.
- **Загрузка расписания.** Из файла CSV или JSON, вставкой текста из буфера обмена или вручную в приложении. Экспорт в CSV для резервной копии.
- Работает без интернета и без регистрации. Расписание хранится только на телефоне.

Нужна iOS 17 или новее.

## Формат расписания

Одна строка — одна пара, столбцы разделяются точкой с запятой. Такой файл можно сделать в Excel, Google Таблицах или Numbers и сохранить как CSV. Пример лежит в [`Examples/raspisanie-primer.csv`](Examples/raspisanie-primer.csv).

```csv
день;начало;конец;предмет;тип;аудитория;преподаватель;неделя
Пн;09:00;10:30;Математический анализ;лекция;305;Иванов И. И.;
Пн;10:40;12:10;Физика;практика;212;Петров П. П.;нечёт
Пн;10:40;12:10;Химия;лабораторная;Б-101;Сидорова А. А.;чёт
Вт;13:00;14:30;История;семинар;410;;
```

- Обязательные столбцы: **день**, **начало**, **конец** и **предмет**. Остальные можно оставить пустыми.
- **День** записывается как `Пн`, `понедельник`, `Mon` или цифрой от 1 до 7. Если день пустой, берётся день из строки выше.
- **Время** пишется как `9:00` или `9.00`. Можно указать интервал в одном столбце: `9:00-10:30`.
- **Неделя.** Пусто — пара идёт каждую неделю. `нечёт`, `числитель` или `верхняя` — по нечётным неделям. `чёт`, `знаменатель` или `нижняя` — по чётным.
- Разделитель может быть `;`, `,` или табуляция. Первая строка-заголовок необязательна; если она есть, порядок столбцов может быть любым.
- Кодировка UTF-8 или Windows-1251: в ней сохраняет CSV русский Excel.

Если какие-то строки не удалось разобрать, приложение покажет, какие именно и почему. Остальные строки всё равно загрузятся.

Перед загрузкой файла откройте в приложении **Настройки → Чётность недель** и проверьте, какой сейчас считается неделя. Если неправильно, переключите.

## Как установить на iPhone

Приложение распространяется в виде исходного кода, поэтому его нужно один раз собрать и поставить на телефон.

### Если есть Mac (самый простой способ)

1. Установите Xcode 16 или новее из App Store.
2. Скачайте проект (зелёная кнопка **Code → Download ZIP** на GitHub или `git clone`) и откройте `Raspisanie.xcodeproj`.
3. В Xcode откройте **Settings → Accounts** и войдите со своим Apple ID. Подойдёт и бесплатный.
4. Выберите проект **Raspisanie**, затем по очереди цели **Raspisanie** и **RaspisanieWidget**. На вкладке **Signing & Capabilities** для каждой укажите в поле **Team** свой аккаунт.
5. Подключите iPhone кабелем, выберите его вверху окна и нажмите ▶︎ (Run).
6. При первом запуске включите на телефоне **Настройки → Конфиденциальность и безопасность → Режим разработчика**. Затем в **Настройки → Основные → VPN и управление устройством** разрешите своего разработчика.

Если Xcode пишет, что идентификатор уже занят, поменяйте **Bundle Identifier** у обеих целей (у виджета он должен начинаться с идентификатора приложения). Затем в **Build Settings** проекта измените `APP_GROUP_ID` на `group.` плюс ваш идентификатор.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно заново запустить из Xcode. Расписание при этом не теряется. С платным аккаунтом разработчика (99 $ в год) приложение работает год.

### Если Mac нет

Каждый push в `main` собирается на GitHub Actions на macOS. Готовый неподписанный `.ipa` лежит во вкладке **Actions** → последняя сборка → артефакт **Raspisanie-ipa**. Его можно поставить на телефон с компьютера на Windows или macOS через [Sideloadly](https://sideloadly.io) или [AltStore](https://altstore.io): они подпишут приложение вашим Apple ID. Ограничение в 7 дней для бесплатного Apple ID действует и здесь.

> Этот способ не проверялся на реальном устройстве. Виджету нужна общая с приложением папка (App Group). Если после установки виджет пишет «Добавьте пары в приложении», хотя пары добавлены, значит, инструмент установки не настроил App Group. Тогда нужен способ через Xcode.

## Как добавить виджет на экран блокировки

1. На заблокированном экране нажмите и подержите палец.
2. Нажмите **Настроить** и выберите экран блокировки.
3. Нажмите на область под часами и выберите **Расписание**. Однострочный вариант добавляется в строку с датой над часами.

## Устройство проекта

```
App/            приложение на SwiftUI
Widget/         виджеты (WidgetKit)
Shared/         код, общий для приложения и виджета: хранение в App Group, форматирование
ScheduleKit/    Swift-пакет с логикой: модель, расчёт следующей пары, чётность недель, импорт и экспорт CSV
Config/         Info.plist и entitlements
Raspisanie.xcodeproj
```

Новые файлы в папках `App`, `Widget` и `Shared` Xcode подхватывает сам, добавлять их в проект вручную не нужно.

Тесты логики запускаются без Xcode, достаточно Swift 5.9 или новее:

```bash
swift test --package-path ScheduleKit
```
